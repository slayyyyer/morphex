Measured claim: faster than stock 2.0 on repeated lookup (0.83×), 1.34× slower on distinct-word lookup (down from 2.4× before the packed layout), lower allocation everywhere, 54% smaller retained heap, substantially higher accuracy. No distinct-word speedup is claimed.

Startup & footprint

50,000 cold miss-heavy calls60.7–61.8 ms
Lexicon entries150,267 (7.71 MB TSV, 1.21 MB gzip)
Retained heap after load24.1 MB (was 55.5 MB)

Load is slower than the old map (426 vs 309 ms) — one-time column packing + index build, not per-lookup cost. No model or native memory: the learning experiment was rejected.

Reproduce

./mvnw -q -pl inflector-benchmarks -am package
java -jar inflector-benchmarks/target/benchmarks.jar \
  -f 2 -wi 3 -i 5 -w 1s -r 1s -prof gc \
  -rf json -rff results/benchmarks/jmh.json

Same-run ratios are the fair comparison; cross-run absolutes are noisy (the rules-only control moved 476 → 391 ns between runs). The final run did not capture concurrent benchmarks — no concurrency claim is made.
