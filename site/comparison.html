Why the accuracy differs

  1. Lookup/casing conflation in stock 2.0. The exception table is reached lower-cased but re-cased as a suffix edit: German → Germen, CHILD → CHILDren. Fixed here by separating lookup normalization from output case restoration.
  2. Lexical exceptions as suffix rules. carp (invariant) infects scarp; louse → lice reaches blouse → blice. Fixed here: lexical knowledge is whole-word edits; only three productive rules exist.
  3. Compounds. Stock inflects the wrong constituent (mother-in-laws, attorney generals). Fixed here with a bounded reviewed table; unmatched input is left unchanged.

Migrate

// before
String plural = org.atteo.evo.inflector.English.plural(word);

// after — build once, share (construction loads the lexicon)
private static final EnglishInflector INFLECTOR = EnglishInflector.standard();

No org.atteo.evo.inflector shim ships on purpose (it would duplicate the API on the benchmark classpath). Caller overrides take precedence over everything: builder().override("information", "informations").
