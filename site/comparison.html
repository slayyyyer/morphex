The delta engine answers pluralize() from 1,962,900 B raw / 562,893 B gzip; the full engine is 3,707,556 B raw / 785,131 B gzip; the rules-only entry point ships no data. The delta engine builds a 1 MiB open-addressed hash index over its 124,883 keys, taking its rule-word path from 673–678 ns (four binary searches) through 286–293 ns (one merged binary search) to 112–118 ns. Provider construction measures 50–51 ms end to end (32–33 ms parsing, 17–19 ms building the index), down from 77–81 ms before the construction changes. Method and spread: morphex-ts/BENCHMARKS.md.

Where the differences come from

  1. Lookup and casing in one step. Stock 2.0 reaches its exception table lower-cased but re-cases the result as a suffix edit: German → Germen, CHILD → CHILDren. This library separates lookup normalization from output case restoration.
  2. Lexical exceptions that behave like suffix rules. carp (invariant) covers scarp; louse → lice reaches blouse → blice. This library stores lexical knowledge as whole-word edits and keeps only three productive rules.
  3. Compounds. Stock 2.0 inflects a different constituent (mother-in-laws, attorney generals). This library uses a bounded reviewed table and leaves unmatched input unchanged rather than guessing.

Qualifications: P1 is dictionary coverage, not generalization. External EWT overall accuracy is 98.76% vs 98.12%; 98.88% on full-vocabulary-seen lemmas and 96.69% on compact-artifact hits, but only 36 EWT lemmas are genuinely unseen. The larger AGID 2016.01.19 stress test has 261 unseen lemmas, where the lexicon and rules-only tie at 95.40% (249/261); AGID is automatically generated, and its 93.84% lexicon overall is dominated by MASS/invariant identity returns, not natural-text accuracy. Current P2 has 4 more errors than the historical v1 measurement (955 vs 951).

Migrate

// before
String plural = org.atteo.evo.inflector.English.plural(word);

// after — build once, share (construction loads the lexicon)
private static final EnglishInflector INFLECTOR = EnglishInflector.standard();
String plural = INFLECTOR.pluralize(word);

No org.atteo.evo.inflector shim ships on purpose (it would duplicate the API on the benchmark classpath). Caller overrides take precedence over everything: builder().override("information", "informations").

Which should you use? Stay with evo-inflector 2.0 if you want the smallest thing that works — no data file, static API, well understood. Choose this library if the rows above matter to you and you can carry the 7.55 MB TSV (1.18 MB gzip, ~18.2 MiB retained) — or use the rules-only runtime mode, which does not load the data but does not remove it from the JAR or its CC BY-SA obligations. It loses irregular forms.

Python baseline: inflect 7.6.0

The most widely used Python pluralization engine, scored on the historical v1 P1 protocol (36,239 primary / 50,938 overall, default modern mode). These baseline numbers are retained as historical evidence and are not current v2 measurements. Full write-up in docs/python-baseline.md.

inflect agrees on the headline irregulars (German, blouse, person → people, die → dice) and shares the passer-by → passer-bies weakness. Its misses concentrate in initialism casing (UFO → UFOS, 0/1,110 on the initialism slice), classical -us forms, and mass nouns pluralized — the same structural overall-accuracy story (67.08% vs 68.83% evo2).
