english-inflector · Java 17+

Pluralize English nouns. Deterministically.

A Java library in the spirit of evo-inflector: predictable runtime behaviour, no dependencies, no network calls, no model downloads. A 150k-entry auditable lexicon, three productive rules, and a diagnostic API that says why a form was chosen.

Quickstart


EnglishInflector inflector = EnglishInflector.standard();

inflector.pluralize("child");          // "children"
inflector.pluralize("CHILD");          // "CHILDREN"
inflector.pluralize("UFO");            // "UFOs"
inflector.pluralize("mother-in-law");  // "mothers-in-law"
inflector.pluralize("cat", 1);         // "cat" (source instance kept)
inflector.pluralize("cat", 3);         // "cats"

Inflection r = inflector.analyze("die");
r.plural();          // "dice"
r.alternatives();    // ["dies"]
r.ambiguous();       // true
r.source();          // LEXICON — "lex:die"






  
How does it compare?

  
evo-inflector is a compact, well-loved library; this project grew out of wanting a few more edge cases covered. Two design choices explain the differences: lookup normalization is kept separate from output case restoration, and lexical exceptions are whole-word edits rather than suffix rules, so carp can’t affect scarp and louse can’t affect blouse. That trades a larger data file for fewer surprises. evo-inflector’s smaller, simpler approach may suit you better if you don’t need the extra coverage.
